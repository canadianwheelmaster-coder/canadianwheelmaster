## 🚀 Deployment

This is a single-file static website. No build tools or dependencies required.

1. Upload `index.html` to this repository
2. Go to **Settings → Pages → Source: Deploy from branch → main → / (root)**
3. Click **Save** — your site is live in ~60 seconds
